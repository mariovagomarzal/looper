# Looper

A window manager for macOS.

## Acknowledgements

Looper takes many of its ideas from two window managers:

- [AeroSpace](https://github.com/nikitabobko/AeroSpace), for its virtual workspaces and tiling model.
- [Loop](https://github.com/MrKai77/Loop), for its radial menu and window controls.

Thanks to their authors and contributors.
